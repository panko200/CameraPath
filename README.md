# CameraPath

製作者：Panko200  
配布場所：https://github.com/panko200/CameraPath

## 概要

YukkuriMovieMaker4 にて、カメラの位置を3Dパスに沿わせて動かすことができるようになる映像エフェクトプラグインです。グループ制御にも使えます。

## 使用方法

1. プラグインをインストールして YMM4 を起動する。
2. 任意のテクスチャの存在するアイテムを追加する
3. 「CameraPath」という映像エフェクトをかける。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `CameraPath` という名前のフォルダを削除する。

## 注意点

OS : Windows 11 (64bit)  
ゆっくりMovieMaker4 : v4.55.1.1  
CPU : Ryzen 7 9700X  
GPU : NVIDIA Geforce RTX 4070 Ti  
RAM : DDR5 64GB  
にて動作確認をしています。
